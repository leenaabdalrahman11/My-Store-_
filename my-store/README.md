# MyStore
MyStore is an Angular e-commerce single-page application that allows users to browse products, view product details, add items to a cart, and complete checkout.
## Features
- Product list
- Product details page
- Shopping cart with total price
- Remove products from cart
- Checkout form with validation
- Order confirmation page
- Angular routing without page reload
## Technologies Used
- Angular
- TypeScript
- Angular Router
- Angular Forms
- Angular Material
- HttpClient
- HTML
- CSS

## Installation
```bash
npm install
```

## Running the Project
```bash
ng serve
```

Open:
```text
http://localhost:4200/
```

## Build
```bash
ng build
```

## Data Source
Products are loaded from a backend API using Angular HttpClient.
